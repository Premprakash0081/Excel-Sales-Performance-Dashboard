# 📊 Sales Performance Dashboard | Excel

## 📌 Project Overview

The Sales Performance Dashboard is a data analytics project developed using Microsoft Excel to analyze sales performance, revenue, costs, and profitability across different regions, product categories, and time periods.

The project demonstrates how raw sales data can be cleaned, transformed, analyzed using Pivot Tables, and presented through an interactive dashboard to generate meaningful business insights.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Understand monthly and yearly sales trends.
- Compare sales performance across different regions.
- Evaluate sales across product categories.
- Transform raw sales data into a structured format for analysis.
- Present key business metrics through a visual dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel** — Data analysis and dashboard development
- **Pivot Tables** — Summarizing sales and profit data
- **Excel Formulas** — Calculating sales, costs, and profitability metrics
- **Excel Charts** — Visualizing sales performance
- **Data Cleaning** — Preparing raw data for analysis
- **Data Visualization** — Presenting business insights clearly

## 📂 Project Structure

- `Sales_Data_Raw` — Contains the original sales dataset.
- `Clean sales performance Data` — Contains cleaned and transformed data, including calculated fields.
- `Pivots` — Contains Pivot Tables used to summarize and analyze the data.
- `Sales Performance Dashboard` — Presents key metrics and visualizations in a dashboard format.

## 📊 Dataset Overview

The dataset contains sales records for the years 2024 and 2025.

Key fields include:

- Order ID
- Order Date
- Region and City
- Salesperson
- Customer Segment
- Product Category and Sub-Category
- Product Name
- Sales Channel
- Order Status
- Units Sold
- Unit Price
- Discount Percentage
- Unit Cost

The cleaned dataset also includes calculated fields such as Year, Month, Sales Amount, Total Cost, Profit/Loss, and Profit Margin.

## 🔄 Project Workflow

### 1. Data Preparation
Reviewed the raw sales dataset and organized the data for further analysis.

### 2. Data Cleaning and Transformation
Prepared the sales records and created additional analytical fields to support time-based and financial analysis.

### 3. Calculated Metrics
Used calculated fields to derive important business measures, including:

- Sales Amount
- Total Cost
- Profit/Loss
- Profit Margin Percentage
- Year and Month

### 4. Pivot Table Analysis
Created Pivot Tables to summarize sales and profitability information and compare performance across different dimensions.

### 5. Dashboard Development
Organized the analysis into a dashboard using Excel charts and key performance indicators.

## 📈 Dashboard Features

- **Sales Analysis:** Overview of sales performance.
- **Sales by Region:** Comparison of sales across regions.
- **Sales by Category:** Analysis of sales across product categories.
- **Profit Analysis:** Overview of profitability.
- **Monthly and Yearly Analysis:** Comparison of sales trends across time periods.
